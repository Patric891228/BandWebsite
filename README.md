# 樂團演出歌單

一個簡單的樂團演出歌單網站。使用者可以瀏覽演出場次，查看每場演出的歌曲與 YouTube 影片縮圖。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。網站會從 Google Apps Script 端點載入演出與歌曲資料；需要網路連線才能取得資料。

## 專案檔案

- `index.html`：網站頁面結構
- `style.css`：頁面樣式
- `script.js`：載入資料、顯示演出與歌曲

## 使用技術

- HTML、CSS、原生 JavaScript
- Tailwind CSS CDN
- GSAP 動畫
- Google Apps Script 資料來源
